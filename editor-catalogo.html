Como publicar no GitHub pelo iPhone

1. Toque em Exportar catalog.json e salve o arquivo no app Arquivos.

2. Abra data/catalog.json no GitHub.

3. Edite o arquivo no GitHub, substituindo todo o conteúdo pelo JSON exportado, e confirme o commit. Se o iPhone não permitir copiar o conteúdo do arquivo, use a opção de upload no GitHub ou envie o JSON aqui para eu aplicar com sua autorização.

4. Confira o catálogo na branch de desenvolvimento. Não publique na main sem autorização. Esta ferramenta não calcula frete, recebe pagamentos ou gerencia pedidos.
